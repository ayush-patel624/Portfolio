Welcome to the source code for my personal portfolio website!

🌍 **Live Website:** [Ayush Patel Portfolio](https://ayushpatel.vercel.app/) *(Assuming the Vercel link matches your domain setup)*

## About This Repository

This repository contains the front-end code for my personal portfolio. It is designed to be modern, highly interactive, and visually striking, showcasing my experience and projects in **Software Engineering, Machine Learning, and Backend Systems**.

### Key Features
- **Interactive Canvas Background:** A scroll-driven image sequence creates a smooth, video-like background animation that responds to user scrolling.
- **Modern UI/UX:** Built with a clean dark theme, utilizing glassmorphism and tailored typography (Inter & Outfit).
- **Responsive Layout:** fully optimized for both desktop and mobile viewing.
- **Showcase Sections:** Detailed sections for Experience, Selected Projects (like *Mental Health Predictor* and *Zivro*), Skills, and Achievements.

## Tech Stack
- **HTML5:** Semantic structure and accessible layout.
- **CSS3:** Custom variables, flexbox/grid layouts, responsive media queries, and modern aesthetic styling (no CSS frameworks used).
- **Vanilla JavaScript:** Powers the canvas-based scroll animations.

## Local Setup

To run this project locally, simply clone the repository and open `index.html` in your web browser, or use a local development server.

```bash
# Clone the repository
git clone https://github.com/ayush-patel624/Portfolio.git

# Navigate into the project directory
cd Portfolio
```

If you use VS Code, you can use the **Live Server** extension to host it locally and test any changes with hot reloading.
